theuth is an AI harness you run yourself: one binary, `t`, whose engine runs sessions, tools, agents, schedules and channels on your own machine. It works with any model, including local ones, briefs and watches external coding agents (Claude Code, Codex, OpenCode, omp), pairs your machines into one encrypted mesh, and keeps your keys in a vault the model never reads. These pages cover installing it, working in it, automating it and configuring it.
