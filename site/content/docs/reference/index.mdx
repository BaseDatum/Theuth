This section is the lookup half of the docs. It names every file in the data
directory, every `config.yaml` key with its real default, every built-in tool
with its risk class, every CLI flag and slash command, and the error strings
you will actually see. Each page is written from the repository source
(config structs, defaults, CLI definitions) rather than from design notes.

If you are new, start with [Getting started](/docs/getting-started) and come
back here when something needs an exact answer.

## Conventions used here

- `<data_dir>` is `~/.theuth` unless `--data-dir` or `THEUTH_DATA_DIR` moved it.
- The binary is `t`. Homebrew installs it as `t`; `just run -- <args>` runs the same binary from a checkout.
- Defaults quoted in tables are the values the code falls back to when a key is absent, not merely what the first-run template shows.
- Tokens such as `{{secret:NAME}}`, `<job_result>` or `THEUTH_<SECTION>__<KEY>` are literal syntax; copy them as written.
