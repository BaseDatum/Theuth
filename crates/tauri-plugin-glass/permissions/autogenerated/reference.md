## Default Permission

198 phase 1: every glass command and the `tap` event listener.

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-configure`
- `allow-set-title`
- `allow-set-scroll-button`
- `allow-set-hidden`
- `allow-set-background`
- `allow-register-listener`
- `allow-remove-listener`
