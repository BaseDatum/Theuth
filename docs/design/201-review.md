## R1 — turn loop, tail, trims, generations, cache stability

Verdict: within one process, for a chat on the endless frame, the main path is sound (each request extends the previous one byte for byte inside a generation; no trim separates a tool call from its results; at most four Anthropic cache marks). The weak points are around it: restarts and resumed turns, edits to the history, the cold-cache rule, deleting a session. (R1 could not run `git diff`; it reviewed the regions tagged 201 by reading the files.)
