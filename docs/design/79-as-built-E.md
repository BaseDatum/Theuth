## Decisions / deviations (nobody to ask)

- **Sliders are native `<input type="range">`**: `components/ui` has no slider; the ladder says platform first. Values sit in the label; release (`pointerup` / `keyup`) is the resize commit.
- **Running-turn detection uses `list_sessions` (`owner` + `running`), not `sessions_status`**: `SessionsStatus` is `{engine, here, elsewhere, log_seq, last_snapshot}` — no per-engine turn state. Same for the row's "N running". The pop-out polls it every 5 s.
- **`VmSnapshot` type lives in `store/sandboxes.ts`**: `export.rs` writes two `SnapshotInfo`s (sandbox's and the documents crate's `{name,label,at_ms: bigint,bytes: bigint}`); the second wins in `bindings/SnapshotInfo.ts`, so `VmView.snapshots` is mistyped. The UI casts through `vmSnapshots(info)`; `sandbox_snapshot` is typed as `VmSnapshot`. Fixture snapshots are `as never` for the same reason.
- **`Changed` type collision**: `ScheduleEvent` already has `{ type: 'Changed' }` — `on('Changed')` handlers guard on `'sandbox' in e`; the routines page gets a spare invalidate on every VM change (harmless).
- **Desktop header item is `slot: 'menu'`**: `lib/header.test.ts` pins the exact tier‑1/2 bar; the full bar (tier 0) shows the button inline, compact tiers list it in the chevron menu.
- **`answer_secret`'s TS signature widened** to `string | Record<string, string> | null`. Single-field cards send the 37 string (works against today's engine); forms send `{ name: value }` — H's `answer_secret { id, values }` must accept both. There is no RPC listing `secret_requests` rows and `AttentionItem` carries no fields, so a `secret` inbox item is only answerable inline on the engine that saw the local `SecretRequested`; elsewhere the card points at the session.
- **Hand-off → VM** mapping uses `AttentionItem.detail` (contract §2.7: the VM name when the engine is a VM record here, else the engine id); both are tried.
- **Bootstrap image** sends `{ kind: 'bootstrap', base: 'ghcr.io/superradcompany/debian-systemd:12', script: '' }` — A: treat an empty `script` as the bundled `bootstrap.sh`; the UI has no script editor.
- **`OpenDesktop` opens only from the main shell** (`!isPopout()`), otherwise every open window would call `open_window` (focus-if-open, so merely noisy).
- **Preflight refetches on every focus** (`refetchOnWindowFocus: 'always'`, `staleTime: 0`) — the engine-scope default `staleTime: 30_000` would otherwise swallow the brief's "on focus".
- **Create reply is inserted into the cache** in `onSuccess` so the row is there even when the `Changed` event is late; `upsert` then replaces it.
- **Only `backend === 'vm'` rows are listed**; docker/ssh records are the existing nodes list.
- **`?sim=` is not dev-gated** (the `?mock=1` precedent is not either); `simFlag` accepts exactly the two values.
- Commits: D2, D3 and D4 landed as one commit (`SandboxVms.tsx` imports the sheets; splitting would break `bun run check` mid-way).
