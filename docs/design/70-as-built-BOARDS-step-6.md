# 70 — as-built BOARDS step 6: sections, TOC, typography, reveal

Design 71 v2 §5 row 6. Branch `71/step-6-sections-toc-type-reveal` (worktree of `feature/71-boards`, base `3398f626` = steps 1, 2, 3, 4, 7a). Mechanisms served: M2 (the fixed section order is what the TOC shows — sections derive from `##` blocks in document order, never re-sorted), M7 (progressive reveal: block rise, unit stagger, the drawing badge), M8 (two type registers: Newsreader prose, mono chrome; `boards.serif` opt-out), M9 (collapse persisted per board and block, collapsed summary, TOC rail ≥ 1360 / pill, expand-before-scroll). Architecture: §2.2 sections/TOC and the `[rail | column | pane]` grid, §2.7 tokens (`--font-serif` consumed, `--edge-muted` added, `--marker-tint` kept), §2.8 reveal + badge. `crates/desktop/ui` only; no Rust, no RPC, no document change.

## What was built

- **`components/board/Sections.tsx`** (new) — `sectionsOf(blocks)`: splits the top-level blocks on `heading level 2`; everything before the first `##` is the preamble (`heading: null`; a frontmatter-only preamble is dropped). `tocOf(blocks)`: `#/##/###` entries in order, each `###` tagged with its enclosing `##`. `countAnchors(blocks)`: `code:` links (paragraphs, list items, table cells, nested children), one per top-level `Excerpt`, one per `ref` inside a `Graph`/`Sequence` spec — the "M anchors" of the collapsed summary. `collapseKey(doc, blockId)` = `board:<doc>:<blockId>`; `useCollapsed(doc, ids)` reads those `localStorage` keys at mount (`'1'` = collapsed), `toggle`/`expand` write and remove them — nothing touches the Yjs document. `SectionView`: `<section class="board-section" data-section data-collapsed>` → `.board-section-head` (chevron `button` with `aria-expanded`/`aria-controls`, the `h2` rendered by the reader, the summary `N blocks · M anchors` in `.board-chrome` while collapsed) and `.board-section-body`, **unmounted** while collapsed.
- **`components/board/Toc.tsx`** (new) — `activeHeading(tops, viewportHeight)`: Whiteboard's `activeTargetForScroll` (first heading at/below the scroller top is active if it sits in the top half, else the previous; past the last, the last). `useActiveEntry(scroller, entries)`: rAF-throttled passive scroll listener on `.board-scroll`. `useRail(pinned)`: rail iff viewport ≥ 1360 px and (no pane or viewport ≥ 1940 px). `Toc`: `<nav class="board-toc board-chrome" aria-label="Contents">` with the 32×32 pill (`TableOfContents` icon), the 248 px card (`Contents` micro-label, close, `ol` of entries with `data-level`, `data-active`, `aria-current="location"`); `Escape` closes the card; picking an entry closes it and calls `onSelect`. A `TODO(71 step 5)` marks where **Tour this board** goes (no `Tour.tsx` in the base at merge time).
- **`components/board/Reveal.tsx`** (new) — `freshIds(seen, blocks)` (pure): the first call is the baseline (nothing fresh), later calls return ids unseen so far. `useReveal(blocks)` → `{risen, last}`: `risen` accumulates every id that arrived after the first render (sticky for the mount, so a 240 ms rise is never cut short by the next insert), `last` is the newest arrival (the badge's section). `StaggerFrame`: the wide diagram frame; decided at mount, a fresh frame carries `data-rise` and a `MutationObserver` stamps `--unit-i` on every `[data-node]`/`[data-step]` as the renderer emits them (the `Graph` lays out through the 65 §4.3 queue after mount), then drops the marker after 2 s so a re-layout never replays the stagger. `DrawingBadge({doc, section})`: `useNoteChat(notes[doc].session)` → `useSessionField(session, 'running')` → `theuth is drawing · <section>`, `role="status"`.
- **`components/board/board.css`** — two registers: `.board-prose { font-family: var(--font-serif) }` (h1–h3 carry `.board-prose`), `.board-chrome { mono 11 px, .04 em }`, `.board-micro` (10 px w700 .08 em); `.board-shell[data-serif='false'] { --font-serif: var(--font-sans) }`; `--edge-muted`; catalog surface blocks (`Checklist`, `Callout`, `Table`…) and `Sequence` SVG text join the mono register. Grid is now `[rail | column | resizer | pane]` with explicit `grid-column`s (`--board-rail` 0 → 248 px under `.board-page[data-rail]`); block width rules cover `.board-section-body > *` as well as `.board-column > *`. Section header (flex baseline gap 10, `margin-block: 40px 12px`, chevron 18×18 at `left: -24px`, rest opacity .45, rotates −90° collapsed; collapsed `h2` → `muted-foreground`; chevron inline ≤ 720 px container). TOC pill (`top: 32px; left: 24px`, radius 8) → 248 px card; ≤ 720 px the open card is a bottom sheet; `[data-rail]` makes it a static grid column with no chrome. Badge: sticky mono chip, top-right of the column, pulsing dot. Motion: `board-rise` (opacity 0→1, 6 px, 240 ms) on `[data-rise]`, `board-unit` with `animation-delay: calc(var(--unit-i) * 40ms)` on units inside a rising frame; `@media (prefers-reduced-motion: reduce)` → `animation: none`, units opaque, no chevron transition.
- **`components/board/BoardReader.tsx`** (additive hunks) — `sectionsOf`/`tocOf`/`useCollapsed(provider.id, …)`/`useReveal`/`useActiveEntry`/`useRail`; `jump(entry)` expands the entry's section then `scrollIntoView` on the next frame (`behavior: 'auto'` under reduced motion, else `smooth`); `data-serif` on `.board-shell`, `data-rail` on `.board-page`; `<Toc>` as the grid's first child, `<DrawingBadge>` inside `.board-scroll`, the column renders the preamble's `Blocks` then one `SectionView` per `##`. `FreshContext` + `useRise(id)` put `data-rise` on every block root (heading, prose div, list item, rule, table, code, excerpt frame, fallback); the diagram case renders through `StaggerFrame`.
- **`lib/boards.ts`** (new) + **`components/settings/General.tsx`** (additive) — `useBoards().serif` persisted under `localStorage['boards.serif']` (default on), rendered as a `Row`+`Switch` "Serif prose on boards" under General › Theme.
- **Tests** — `Sections.test.ts`: preamble/section split, anchor counts on the fixture's `Graph` (refs + excerpt), TOC nesting, the M6 scroll rule (six cases), the reveal core (baseline, fresh once, removals). `registers.test.ts` (the CSS register test): `board.css` names exactly the two faces `var(--font-serif)` and `var(--font-mono)`; `.board-prose` is serif, `.board-chrome` mono 11 px, the `data-serif='false'` override swaps prose to `--font-sans` only, the only `.board-prose …` family re-declaration is inline `code`; rendered `SectionView` (collapsed summary, unmounted body, `aria-expanded`) and `Toc` (class, active entry, `aria-current`) via `renderToStaticMarkup`.

## Deviations

1. **Rail breakpoint is the viewport, not the shell container.** §2.2 says "the rail exists at ≥ 1360 px"; R §B.3/§346 measure Whiteboard's *shell* = window. theuth's shell sits beside a 260 px sidebar, so at a 1440 px window the board container is 1180 px — a container query would hide the rail exactly where the Done-when wants it. `useRail` uses `matchMedia('(min-width: 1360px)')`.
2. **The pane takes the rail's place below 1940 px.** Rail + column + pane at 1440 left a 362 px column (prose 322 px). The rail yields to the pane (TOC becomes the pill) unless the window is ≥ 1940 px (260 + 248 + 860 + 570), where both fit with the column at 860. Not in the design, which never puts numbers on the three-column case.
3. **Third register on `Graph` labels.** Graph nodes/edges keep `--font-sans`: `Graph.tsx` measures label widths in `diagramTokens().font` (`--font-sans`) before layout, and a mono override under the board leaves boxes fitted to the wrong face (measured: `closing()` 70 px of text in a 78 px box, no padding left). `Sequence` text (fixed lanes, labels above arrows) and the catalog surface blocks (`Checklist`, `Callout`, `Table` inside a board) are restyled to mono. Making `Graph` measure in the board's face belongs to the component, not to `board.css`.
4. **Collapsed sections unmount their body** instead of `hidden`. A hidden `Graph` would lay out at zero width and the tour/anchor registry would hold entries for things the reader cannot see; remounting on expand costs one render, and no rise plays because the ids are already in the baseline.
5. **Rise is decided per block id, not per `Authored` event.** §2.8 says "block ids unseen at the previous render get the rise" — implemented exactly so; `provider.onAuthored` is not consulted. Consequence: any insert (agent, another device, a script) rises; the drawing badge is the only thing gated on the bound session.
6. **`data-rise` stays on a block for the rest of the mount** (the `StaggerFrame` alone drops it after 2 s). With six inserts 30–50 ms apart, removing the attribute at the next render cancelled the 240 ms animation mid-way. The CSS animation runs once at insertion either way; the sticky attribute changes nothing visible.
7. **Anchor count is static** (`countAnchors` over the blocks), not read from the anchor registry: the registry is empty for a collapsed (unmounted) section and diagram units join it only in step 5. The count includes `Graph`/`Sequence` `ref`s today, so it will match the registry once step 5 lands.
8. **"Tour this board" is a TODO in `Toc.tsx`.** Step 5's `Tour.tsx` is not in the base; the brief said so.
9. **`--fg-muted` does not exist**; the collapsed heading and summary use `--muted-foreground` (= `--fg-secondary`), the §2.7 name.
10. **Grid placement made explicit.** The absolutely positioned pill `nav` is the grid's first child; without `grid-column` on `.board-scroll`/`.board-resizer`/`.board-pane`, the scroll column fell into the 0 px rail track at 1024 (found in the smoke: `.board-scroll` width 0). Fixed in `board.css`, not a behaviour change.
11. **The setting lives in Settings › General**, not a new Boards tab — one row beside Theme, the smallest additive hunk in `SettingsDialog`'s owner file.

## Findings for later steps

- **Step 8's binding is what the badge waits for.** Today nothing writes `note-chat[doc].session` for a board the agent created; the smoke set it by hand. Once `BoardCard`/`doc_create(kind=board)` binds the session (§2.11), the badge works without any change here.
- **The scratch engine reports the documents helper missing** (`target/debug/theuth-documents-59.5`); `doc_update` still round-trips because the reader is headless BlockNote. Anyone reproducing the smoke from a fresh worktree needs `cargo build -p document` (or the helper) only for derived-markdown paths.
- **Unit stagger depends on `[data-node]`/`[data-step]` order = authored order** (true for `Graph.tsx`/`Sequence.tsx` today). Step 5's tour ordering should keep it.
- **Pinned + rail on a very wide window** is the only three-column case; 1940 px is a floor, not a design number — revisit if the sidebar width changes.
