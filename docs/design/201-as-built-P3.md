D6 D7 D8, §6 queue / lazy merges / local endpoints, §7.1–§7.3.

## Landed

- **`endless/lines.rs`** (new, pure): `draft_line(unit, node_bytes)` per kind — `tool: <name> k=v, …` (JSON args, each value cut to 60 B, args dropped whole when they no longer fit); `echo: <first> | <error lines> | <last> (N lines, M errors)`; `user`/`note` one line, verbatim, a head ending at a sentence end plus as much of the end as fits (starting at a sentence start); `talk`/`work` = `tree::mechanical_unit`. Every line ends in `cut_words(…, node_bytes)`. `needs_model(unit)`: talk/work always, echo only over `ECHO_MODEL_OVER` (2,048 B) with no error line, tool/user/note never. Module tests cover shape, bound, determinism, tag per kind.
- **`pump.rs` `draft_node`**: a unit that does not fit and needs no model stores its per-kind line as `Quality::Free` (final, never queued); else `Draft` with the per-kind line. The old `pump::draft_line` is gone.
- **Profile (§7.1)**: `pump::resolve_profile(want, model, local) -> (Profile, reason)`; `auto` → small when local or the *known* window (`limit.context`, else `limit.assumed`) ≤ 32,000. `profile_of(state, live)` = desk agent's key over config, against the compactor in force; meeting trees → standard. `AgentTail.profile` (roster sends `f.profile` with the tail keys), `EndlessConfig::with_agent_tail` applies it, `Endless::set_agent_tail` → `pump::set_agent_profile` (live), attach reads it. `SessionMemory.profile`/`profile_reason` filled (no state: the configured pick, `auto` shown as standard "resolved when the summary model runs").
- **Small profile (§7.2)**: `compactor::SMALL` (`small_prompt.txt`, 664 B), `SMALL_REPLY_TOKENS` 160, `SMALL_CTX_BYTES` 2,000, `small_chunk_bytes(window_bytes)` = `(window − prompt − ctx − reply) / 2` clamped 512..=4,096, `small_render(step)`, `build_small` / `small_once` (one attempt, first non-empty reply line, unchanged guards via `accept`; trip → `Built` with negative tries; oversize unit → chunks then one join call). Trait `Compactor::compress_small` (default `compress`; `Tally` forwards); `ModelCompactor::request_small` (SMALL system, 160-token cap + a chosen thinking budget within `carry`, stop sequence `"\n"`); `request_opts` now delegates to `request_with(system, …)` (bytes unchanged). `pump::small_ctx` = "Context:" + the user's last message (≤ 700 B line) + up to 4 previous lines of the same turn, ≤ 2,000 B, no `<chat>`. `Job.small`; `call` skips `fit_ctx`/G5 retry for small. A small guard trip increments `Live.tripped[i]`: 1 → retried only when the level-0 queue is otherwise idle; 2 → draft kept until `endless_retry` (`reset_backoff` clears it).
- **Queue (§6)**: drafting sessions refine `drafts[t_cut..T)` (tail, oldest first) before `drafts[base..t_cut)` (`t_cut` of the current generation). Small → batch size 1.
- **Lazy merges (§6)**: `merges_due(state, live, cfg)`: model merges only when `fold.size() > merge_at × view_bytes` (meeting trees: always), measured at most once per `schedule` pass and only when a model merge is a candidate. Deterministic merges (a draft child, or children that fit) of a drafting session are now built inline in `schedule` — `live.put` in the same pass, so a parent follows at once — and persisted in one `endless_nodes_put` task; no slot, no task per merge, and independent of the pause (paused: no level-0 refinement, no model merges). A meeting tree is unchanged (paused: nothing; merges via `spawn_build`).
- **Local pacing (§6)**: `Gate::acquire(priority, owner)`; `GateState.{owner,last,run}`, `RUN_MAX` 8: the last-served session's best waiter at the top priority wins while its run < 8, then another session's waiter. Priority order kept.

## Deviations

- R2-2 aging now applies only when the oldest waiter is below the top priority (at equal priority the run rule decides; the old rule at equal priority picked the arrival-first waiter, which the run rule replaces). The aging test is unchanged and green.
- "In the fold's own due order": merges are still scanned level by level, oldest first, not in fold order.
- "View as the next trim would fold it" is approximated by the live fold's `size()` over `[base, T)` (tail included).
- Constrained output: nothing in the backend plumbs a response format, so `compactor::small_output_format` is a named seam returning the options unchanged.
- Small also applies to merges (`small_render` Merge, small context), not only units.
- Tests: sessions seeded with long user messages (`seed_many`, and the seeds of `queued_merge_does_not_hold_back_the_frontier`, `over_cost_…`, `long_unit_is_map_reduced_…`, `load_drafts_node_less_units`, `local_compactor_receives_the_capped_view`, `loop_::endless_tests::endless_turn_view_is_bounded_…`, `supervisor::tests::compact_in_an_endless_session_…`) now append assistant (talk) messages, since a long user message no longer reaches the model. `cfg_137f` pins `profile: standard` (its tests use a local probe that `auto` would make small). Assertions that pinned eager merges were relaxed: `pump_builds_tree_…` (≥ 1 call), `failing_unit_blocks_nothing` ((1,1) exists), `built_by` skips draft merges, `queued_merge_…` seeds 24 free lines with `merge_at: 0.5` so a merge is due; the bounded-view loop test checks message 0 is not a level-0 line (paused sessions now fold with draft merges, not only the prefix line). `quiet_for_tests` ignores stale merges while merges are not due and counts a twice-tripped small unit as given up.
- `is_error` (echo) needs `error` at the line start or `error:` / ` error ` / ` failed` / `panicked` / `fatal:` / `exception` / `traceback`; `error_log` is not an error.
- Inline draft merges are persisted by a spawned task after the in-memory insert: two rebuilds of the same key in quick succession could reach the store out of order (the in-memory tree is right; a restart could load the older draft merge, which a later child change rebuilds).
