## Deviations from the design, with reasons

- **Timeout message** is `page_preview: preview timed out after 15 s (the page did not finish loading); console so far: none`.
  §11.4 says "console so far: …", but the engine receives console only inside `Done`; before that there is nothing to
  show. The client's own 10 s `load` timeout answers `Done { loaded: false }` with what arrived, which is the path that
  carries partial console to the model.
- **`loaded: false`** appends one sentence to the §11.5 message line (`The page did not finish loading within 10 s; …`)
  so the model does not read the floor height as a measurement.
- **Height with no post**: `answerOf` reports `MIN_HEIGHT` (80) when the page never posted a size; §11.3 says "the last
  height" and names no fallback. The console carries why.
- **`Started`-less `Done`** is accepted (a client may answer `Done` directly); `first Done wins` is unchanged.
- **`client.rs` `mirror`** does not republish the two events: a mirrored request would be answered against the local
  engine's map (wrong engine, always `false`). The relay-served UI subscribes to the remote engine directly.
- **Error prefix**: tool errors read `page_preview: …` like `show: …`.
- Tool-level timers (2 s / 15 s) are constants; the tests pause tokio's clock instead of a config knob.

## Open items

- Not exercised live: a `page_preview` call against the running desktop (§13.4 "returns height + console in < 3 s",
  "no renderer connected within 2 s with every client closed"). No Tauri shell was run by this worker (the brief forbids
  the Tauri CLI); the DOM wiring in `start()` is covered by type-check only, the timing by vitest, the engine half by
  the rpc tests. The closer's smoke should run it once.
- `receiver_count()` counts every event subscriber (the TUI bridge, a link `Feed` consumer), not renderers; with any
  non-rendering subscriber the "no renderer" answer arrives after the 2 s timer instead of at once. Acceptable per §11.4.
- A second `load` from a page that navigates itself does not restart the settle (`onLoad` keeps the first timestamp);
  the frame is torn down at the deadline regardless.
