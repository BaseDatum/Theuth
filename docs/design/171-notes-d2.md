# 171 CELLS — notes of documents worker D2

Scope: `crates/document` only (`packages/documents` untouched). Decisions where the design or the brief was silent; simpler option, contract intact.

## What is built

1. **`CodeBlockText`** (`cells.rs` stub body → `note_cells.rs`): yrs walk of the live Y.Doc (`blockContainer[id] > codeBlock[language] > text`, pre-order, nested blocks included). `NoteKey::Name` = the one block `surface::cell::parse` reads with `name: <name>` (two → error naming both block ids); `NoteKey::Block` = that block id. `text` = the full code text as the Y.Doc holds it (header + code). Errors: `document <id>: <load error>`, ``no cell named `x` in document <id>``, `no code block <id> in document <id>`.
2. **`last_author`**: member → `Principal::Member{pub_, device: None}` from `meta.authors` (the member-label map); agent → `Principal::Agent{session}`; anything else (owner, undo, file import) → `Principal::Owner{device: None}`. An agent helper transaction attributes both the observer's written ids and the helper's `touched` ids (the `DocEvent::Authored` set): the observer alone misses every block of a first import (`doc_create`), which arrives inside one new `blockGroup` — found by the helper-backed test.
3. **Run annotations** (`note_cells::{annotate_outline, with_runs, reader_markdown}`): only when `run_annotations()` is `Some`. Outline: the helper's `[code:<lang>] …` row of a cell (and its tree `text`) becomes `<hook outline prefix> <first code line> … (N line[s])`, no-run cells `[cell:<lang> <name>] …`; member labels (`  [by …]`) kept. Markdown: after each cell fence the hook has a run for, an `output` fence (backtick fence longer than any backtick run in the text) when `output` is `Some`, then the run line. No hook → the `Outline`/`Markdown` text unchanged (no extra message is even sent for the outline). `cells` defaults blocks are never cells, so they render as they are.
4. **`#|` fence validation** (`CheckCells` message, `Docs::check_cells`): `doc_insert`, `doc_replace` and `doc_create` refuse with `nothing changed: a cell does not validate — fix it and retry` + `cell <n>: <code> — <message>` lines (n = ordinal among the cells of the inserted markdown). Errors only (warnings are the editor's chips). Scope = the note's cells after the edit (replaced blocks removed) + the inserted cells; defaults = the note's first `cells` block, else the inserted one. Vault names come from `Store::vault()` (`Vault::list`), so `secret_unknown` IS checked when the secrets plugin runs; without a vault it is skipped. `monty_ok`/`cwd_exists` stay `None` (Monty and the filesystem are the engine's checks).
5. **`cell_latest`** table beside `sources` (exactly §13.2's columns + `cell_latest_doc` index), fifth entry of `store::TABLES` (so `replica::attach` replicates it per-column LWW). `Store::cell_latest(doc)` (ordered by id) / `Store::put_cell_latest(row)`. `Store::delete` deletes the document's rows (a replicated delete → tombstone). E2's `// 171:E2-ADD` block (`CellLatestOf`, `PutCellLatest`) pasted byte-identical at the end of `cells.rs`; `Hub::gate_str` already existed.

## Decisions / deviations

- **Agent attribution is persisted in a new sidecar `documents/<id>/agents.json`** (block id → session uuid), written with `meta.json` on the same tick/unload. Before, the agent's authorship existed only as the transient `DocEvent::Authored`, so `last_author` would have lost the agent at the first idle unload (600 s) and note-cell results would report to nobody. Not in `DocMeta` (TS-exported, and `crates/tasks` builds `DocMeta` literals). Local to this engine, not mirrored: after a hub move the new hub reports agent-written blocks as the owner's.
- **`.md` export gap (outside my ownership):** the user's `.md` export is `rpc::doc_export`, which asks `document::Markdown{annotate: false}` — the same message `doc_markdown`, the index, tasks and meetings use, so the document crate cannot tell an export apart. `document::reader_markdown(&actor, doc, blocks, annotate)` is the reader rendering; `crates/rpc/src/api.rs` `doc_export` (format markdown) must call it instead of `doc_send(…, Markdown{…})` — a one-line change for the lead/Z.
- **`doc_replace`** runs the same cell validation as `doc_insert` (it inserts markdown at the same site); the design names insert/create only.
- **Membership helper for `cell_latest`**: `document::MayRead{doc, by}` already exists (E2's RPC uses it); nothing added.
- **Matching fences to blocks** (markdown form): fences of the helper's markdown are matched to the Y.Doc's code blocks in document order by first info word = `language` and exact text. Cells nested under list items (indented fences) are not annotated in markdown (their outline row is).
- The hook is called on the async path (outline: tool task; markdown: after the `Markdown` ask): `RunAnnotations::note_cell` must not block (E2's impl is a cache lookup — fine).
