## What was built, file by file

- `crates/autoresearch/src/world.rs` (~1,800 lines incl. tests) — the kind.
  - **Statistics** (§11 "The sequential test", "Harm", "Ratio check"): `lambda(delta, v, tau)` = √(V/(V+τ²))·exp(τ²Δ̂²/(2V(V+τ²))); `ratio_p(a, b)` the 1-df χ² p of the arms' units against 50/50 (`erfc` is Numerical Recipes' `erfcc`, |ε| < 1.2e-7); `cumulate(obs, arm) -> ArmStat` (unit-weighted mean, `Σ units·var/(Σ units)²` as the variance of that mean, unit-weighted extras = guard metrics); `judge(obs, direction, w, tau, guards) -> (Look, Outcome)` in order: ratio p < 0.001 or measured exposure > `max_fraction`·1.05 (when the control rows carry `raw.total`, summed over windows) → `Ratio`; a guard past `max_regression` → `Guard`; Λ ≥ 1/α_harm with Δ̂ < 0 → `Harm`; Λ ≥ 1/α with Δ̂ > 0, ≥ `min_windows`, ≥ `min_units` per arm → `Keep`; `max_windows` → `Inconclusive`; else `Continue`. τ = `world.tau`, else `metric.min_effect` of the base mean.
  - **Measurement**: `parse_arms(case_values)` reads the v2 scanner's `CASE <arm> units= mean= var= …` map (`CASE total units=` is production's traffic); `parse_tool(json, &MeasureTool)` the same from a read-only registry tool's JSON by pointers (W-d). `measure(env, study, n, win)` runs `Backend::plugin_command("measure", …, AUTORESEARCH_N/_WINDOW)` or `Backend::invoke_tool` (refused unless the tool is in `calls` and read-only — C's gate).
  - **`sample`** (every role): one read of the source, the control arm's mean as the value, `units`/`var`/extras as secondaries — the baseline at Start, incumbent re-measures and the launch fire's one candidate sample all read production as it is.
  - **`step`** (the launch fire): refuses a second launch while one waits (one world experiment at a time), writes the `launches` row (`requested`, sha256 of a fresh token), spawns `settle_launch`, answers `GateStep::Wait { until: "your approval" }`. `settle_launch` polls the row until `finish_measure` has written `measured` (`Verdict::Pending`), then `request()`: `wait()` → `Waiting {Approval}`, `launch` event, `pause_for_launch` (`enabled: false`, a `paused` event with `reason: launch_approval`, `Paused { LaunchApproval { n } }`, `StudyChanged`), `post_card`.
  - **The waiting and timer API (frozen, W7 consumes)**: `wait(env, study, exp, info)` writes `Waiting` + `experiments.wait`, disables the schedule file, arms a tokio timer at `info.until` (RFC 3339; `"your approval"` arms nothing; a process-wide registry keyed `(slug, n)` replaces an earlier timer). `resume(env, slug, n)`: a row no longer waiting → file back on, its state; a non-world kind → the kind owns the decision, state returned as is; a terminal/finalizing study → `Abandoned` with rollback; else `window_end`. `rearm(env)` at engine start re-arms one timer per `waiting_experiments()` row with a parseable `until` and returns the count (0 on every 140 ledger). `explains_disabled(store, slug)` = a waiting experiment of that study exists. `armed()` for tests.
  - **The press** `launch(env, slug, n, token, approve)` (via `launch_rpc` for `rpc_impl`): the `launches` row must be `requested` and the token's sha256 must match; the experiment must be `Waiting`. Refuse → `refused`, experiment `Discarded` "refused at launch" (patch saved, tree reset), study resumed with the file enabled. Approve → `snapshot()` commits the worktree off any branch (`add -A`, `write-tree`, `commit-tree -p <incumbent>`) as the candidate sha; two detached worktrees `<study>/arms/{control,candidate}`; `deploy` per arm with `AUTORESEARCH_ARM`, `_TREE`, `_ARM_WORKTREE`, `_EXPOSURE` (= `max_fraction/2`), `_N` — a failing deploy rolls both back and closes `Crashed`; else `deployed`, `wait(Window, until = now + window)`, study back to `running` with the file still disabled (W-i; `reconcile` skips it through `explains_disabled`).
  - **Each window end** `window_end`: measure → one `observations` row per arm (`raw` = every field, plus `total` on the control row) → `judge` → `experiments.gate` = `GateDecision { v: 2, rule: msprt, objectives: [primary Δ], stat: Λ, threshold: 1/α, n: units }`, `delta`, `delta_pct`, `metric` = candidate mean, a `window` event; `Continue` → `wait()` for the next window with `line` = "waiting · window k of at most N · closes <at> · …"; `Keep` → `Kept`; `Harm` → `Discarded` (`Verdict::Worse`); `Guard` → `Discarded` (`GuardFailed`); `Inconclusive` → `Discarded` (`NoGain`, "inconclusive after N windows"); `Ratio` → `Crashed` and the study `Paused { Other { reason } }`.
  - **Close** `close()`: timer off, `rollback_all` (both arms, always; arm worktrees removed; launch → `rolled_back`; failures in the `launch` event), keep = `Backend::keep` + `record_keep(…, StudyPatch::incumbent(sha, candidate mean, σ))`, else `Backend::discard` (patch saved, tree reset), `closed` event, `ExperimentFinished`, schedule file enabled, `actor::after_experiment` (stop rules) spawned.
  - **View/brief/headline/card/setup**: `view` = every `ArmWindow`, the latest launch row, Λ per window of the latest launched experiment; `brief_section` = "## World study" (how the fire, the press and the windows work; after `pending` end the turn, no `experiment_log`) plus the launches so far; `headline` = ledger baseline (else the first launch's control arm) → last kept candidate's cumulated mean with a 95 % half-width, no confirmation samples; `card_line` = "Test `<scope>` on 10 % of traffic in two arms; every launch needs your press; 24h windows (2–14); rollback `…`"; `SETUP_ROWS` `deploy`, `rollback`, `measure`, `exposure`, `windows` (the 140 `window` row is the idle sensor), `min_units` with `setup_value`/`setup_set` over the `world.*` leaves (percent or fraction for exposure, humantime for `window`/`timeout`, levels in (0,1), `max_windows ≥ min_windows`).
- `crates/autoresearch/src/types.rs` — `WorldSpec` (W6-a): `deploy`, `rollback`, `measure`, `measure_tool: Option<MeasureTool>`, `exposure: ExposureSpec { max_fraction: 0.1 }`, `window: "24h"`, `min_units: 500`, `min_windows: 2`, `max_windows: 14`, `alpha: 0.01`, `alpha_harm: 0.05`, `tau: Option<f64>`, `timeout: "600s"`; `ExposureSpec`, `MeasureTool { name, args, arms, arm, units, mean, var }` (JSON pointers). ## Deviations

- **W6-a — `types.rs` `WorldSpec` filled.** `block_specs!` made it `pub struct WorldSpec {}` and types.rs is frozen; the design says the block is "W6's addendum" and nothing in §11 is buildable without its fields. Edit: the `WorldSpec;` line of `block_specs!` replaced by a comment, plus `WorldSpec`, `ExposureSpec`, `MeasureTool` `wire!` structs with `Default` impls (every field defaults; `serde(default)`). Risk: other waves replacing their own `block_specs!` line conflict on adjacent lines — trivial for Z. TS bindings not regenerated (gitignored; `WorldChart` reads only `KindView`; Z's export adds `WorldSpec.ts`, `ExposureSpec.ts`, `MeasureTool.ts` and widens `StudySpec.ts`).
- **W6-b — the engine handle for the press.** `rpc_impl::launch` has no `Env` and no actor message carries one; `world.rs` keeps the `Env` the actor last handed to `rearm`/`sample`/`step`/`wait` in a `static` and `launch_rpc` reads it. Before the first `recover` the RPC answers "the autoresearch engine is not running".
- **W6-c — the launch card needs two tools.** An OpenUI `Mutation` runs only an installed tool and `autoresearch` cannot call `app`, so `launch_card.rs` registers `autoresearch_launch_card` (the plugin posts through the registry, quiet, origin session) and `autoresearch_launch` (the press → `rpc_impl::launch`), one `// 159:W6` line in `app/src/lib.rs` (the table grants "its RegisterTool"; C-i says lib.rs got only `pub mod` — the table was taken as authoritative). Both tools are useless to the model (token-checked). The card is committed with `Origin::Ui` (no transcript entry; the session's artifact list shows it) and a plain notice goes to the origin chat the way `deliver` does (user channel first, else `SendInput` wrapped `<autoresearch … event="launch">`), so the chat always learns of the press even without the desktop.
- **W6-d — the flip to `Waiting` follows the measure loop.** `measure_env`/`finish_measure` (frozen) store the launch fire as `measured` + `Verdict::Pending`, and `log_env` has no pending branch (§11 step 1's "experiment_log on a pending experiment records the text and leaves the state" is unimplemented in C's skeleton). `world::step` therefore spawns `settle_launch`, which flips the row to `Waiting` the moment `measured` lands (50 ms polls, 60 s cap) — before the session's next tool call or turn end in practice; `experiment_log` after that is refused as "no experiment is open", and the skill/brief tell the session to end the turn after `pending`. The description comes from `idea` + `hypothesis`. Exact hand-off below.
- **W6-e — `WorldChart.test.ts` is a new file** (the component's paint test; `components.test.ts` is frozen).
- **W6-f — `resume` for non-world kinds** returns the row's state without a kind hook (no frozen `suite::resume` exists): W7 closes its experiment itself and then calls `world::resume` to get the schedule file back, or calls `wait` again to extend.
- **W6-g — no `ProbeKind::Measure`** (types.rs frozen): setup does not run `measure`/`rollback` itself; the skill tells the setup agent to run them once by hand and show the arms. Hand-off below.
- **W6-h — `harm within 3 windows`** holds at 2,000 units per arm per window for a halved conversion (≥ 95 %, none past 4); at 1,000 units the median is 2 windows but the tail reaches 7. The P test states its parameters.
