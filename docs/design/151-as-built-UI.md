## Deviations (closest correct thing; none reopen a decision)

1. **`new_session` → `create_session`.** The brief/design say `new_session({cwd})`, but `Api.new_session()` takes no options; `create_session(CreateSessionOptions)` is the method that records `cwd` (`lib/drafts.ts` `PLAIN_OPTIONS`). Same order as Routines otherwise.
2. **"Start with my uncommitted changes"** has no slot in `autoresearch.create {draft_id, start}`; the card does it with `mark_include_dirty` inside `autoresearch_start`. The panel sends `draft_edit(draft_id, 'include_dirty', 'true')` then `create`. **Hand-off to ENG:** accept the leaf `include_dirty` (bool) in `draft_edit`'s parser — it is a `StudySpec` field not in §4.3's leaf list. Until then the button toasts the engine's refusal.
3. **Phone pane** is not wrapped in its own full-screen `Sheet`: the Explorer already shows one pane at a time under `md` and hides the rail when `active`, so `/autoresearch/new` *is* the full screen (a Sheet would float over an empty outlet). The second sheet (the panel from the "Draft n of m" pill) is built as specified.
4. **Test file names:** vitest's include is `src/**/*.test.ts`, so the panel test is `DraftPanel.test.ts` (static `createElement` renders, the `components.test.ts` convention), not `.tsx`.
5. **Recent repositories** use a native `<datalist>` on the path field (type-ahead + pick) instead of a separate dropdown control; default = the newest, as ruled.
6. **Edit on every row** (not only proposed): a link under the row for settled/missing/optional rows, so a missing row can be filled in from the panel; proposed rows show OK · Edit inline as in the mock.
7. The idle-window Start uses `spec.window` or `idle.py` (`tools::IDLE_SENSOR`), the same default the card uses.
8. `useStudy` gained an `enabled` parameter (the pane needs the detail only after Start); every existing caller keeps the default.
