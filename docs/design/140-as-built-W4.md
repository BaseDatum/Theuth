## Deviations from the brief / design (and why)

1. **Model pickers are `ModelCombobox`, not a Radix `Select`.** 136's Dreaming page (the named template) uses `ModelCombobox` over `list_models`; a second picker convention would be worse than following the freshest page.
2. **Open PR / Merge into my branch are clipboard buttons.** The contract's `ControlOp` is `pause · resume · stop_after · stop_now · run_once · segment · finalize · restore · discard`; there is no landing RPC (§11.5). Each changeset row's *Open PR* copies its branch, *Merge into my branch* copies `cd <repo> && git merge --no-ff <branch>`; both say so in their tooltip. Hand-off below.
3. **"Keep reverted" has no op** in the contract; the Study view shows *Restore* only. The attention row (W3's) is where §9.1 puts Restore · Keep reverted.
4. **No live sample-log tail.** `StudyDetail` carries no tail and there is no tail stream; the current-experiment panel shows phase chips, the clock and the idea. Hand-off below.
5. **Needs your eyes are strings** (`StudyDetail.needs_eyes: string[]`), not structured items; the panel renders them with `#n` made clickable and a Restore for rows the run table knows as `rejected_by_review`.
6. **Chart colours come from `StudyChartPoint.verdict: string`**, a free tag; `chartOutcome` maps the `ExperimentState` vocabulary and the verdict kinds, anything else grey. Hand-off: fill it with the ledger state.
7. **`events.ts` touched** (not in the ownership list) for the `StudyEvent` union member — without it the event subscription cannot type.
8. **Dev-server watcher**: Vite's file watcher never fired in this worktree (no HMR); each visual round restarted the server. Not a product change.
9. **Screenshots in `docs/design/assets/140-w4/`** (webp, 412 KB) rather than `/tmp`, so the paths outlive the session.

## Mirror → bindings: what changed at the swap

`StudyState`/`PauseReason`/`StopReason`/`ExperimentVerdict`/`ReviewVerdict`/`ControlOp`/`IdeaChange` are tagged objects (`{state}`, `{kind}`, `{op}`), not string unions; `StudyInfo` carries `incumbent{sha,mean,kept}`, `baseline_mean`, `sigma`, `budget_used`, `headline`, `current`/`phase`, `stop_reason`, `report_doc`; `StudyDetail` is `info + spec + playbook + series{experiments,incumbent,holdout,drift,baseline_mean,sigma} + ideas + steers + changesets + needs_eyes`; `ExperimentRow` has no `line`/`duration` (duration = `finished_at − started_at`); `ExperimentDetail` has `line`, `tails: string[]`, `decision`, `parent_sha`, `patch_hash`, `BenchSample` (nullable `load`), `CaseDelta` (nullable `before`); ideas/steers ids are numbers; `autoresearch.steer` returns the row id; settings are the whole `AutoresearchConfig` (durations humantime strings; reviewer model at `review.model`); RPC names `autoresearch.settings.get|set`; `ExperimentPhase` lowercase; `StopReason` has `user_now`/`budget`/`hours`.
