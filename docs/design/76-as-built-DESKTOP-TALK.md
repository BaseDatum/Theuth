# 76 — as built: DESKTOP-TALK (the desktop and phone view of a talk)

Status: built 2026-09-28 on `talk/desktop` (base `feature/talk` @ 763f8bfb). The view is coded against the
TALK-CONTRACT surface (`docs/design/76-as-built-TALK-CONTRACT.md`) and judged through a dev-only simulator;
the engine behind `talk_start` is TALK-CORE's and was not on this branch (see *Not verified*).

## What was built

All under `crates/desktop/ui/` unless noted.

### The orb — `@shadercn/orb-20`

- `src/components/orbs/{renderer.ts, canvas.tsx, orb-20/{index.tsx, meta.ts, gpu.ts}}`, `src/lib/shader.ts`: the
  `orb` (core) and `orb-20` registry items, files as the registry targets them (`components/orbs/…`, not
  `components/ui/` as the brief guessed). Dependencies added: `vgpu ^0.5.0`, `typegpu ^0.12.6`; dev:
  `unplugin-typegpu ^0.12.4`. `components.json` gains `registries["@shadercn"]`.
- `vite.config.ts`: `typegpu({ include: [/\/components\/orbs\/.*\.ts$/, /\/lib\/shader\.ts$/] })` — the
  TypeGPU transform every `'use gpu'` body needs; without it the orb fails at resolve time with *Missing metadata
  for tgpu.fn function body* (observed, then fixed).
- `renderer.ts`: eleven `!` non-null assertions on loop-bounded index reads — the vendored file does not compile
  under this tree's `noUncheckedIndexedAccess`. No other change to the vendored code.
- `src/components/talk/Orb.tsx`: `Orb({state, size, onClick, label})` — a `<button>` around `Orb20` tinted with the
  theme's `--fg-accent`; where `navigator.gpu` is absent or `prefers-reduced-motion: reduce` holds, a CSS orb
  (`.talk-orb`, `styles.css`) shows the same three states (thinking pulses, speaking swells; static under reduced
  motion).

### Talk state — `src/lib/talk.ts`

- `orbState(State) → 'idle' | 'thinking' | 'speaking'` (§0.12 mapping; `holding` → speaking, `interrupted` → idle).
- `Subtitles {agent, speech, user, utts}` + `applySubtitles(s, TalkEvent | SpeechFinished)`: agent line from
  `Saying`, cleared by the matching `SpeechFinished` or `Interrupted`; user line from `Heard` per utterance,
  append-only (a shorter partial that prefixes the current text is ignored; a non-prefix revision or the final
  replaces), cleared on `Submitted`.
- Store `Talk {phase: off|starting|on|stopping, id, session, state, aec, degraded, subs, mine}`; `useTalk()`;
  `handle(e)` (the reducer the bus and the simulator both feed); `installTalkListeners()` (`TalkStarted, TalkState,
  Heard, Saying, Submitted, Interrupted, Flush, Degraded, TalkFinished` + `SpeechFinished`), mounted in `App.tsx`
  beside dictation's; `refreshStatus(api)` from `talk_status` at `loadInfo` (a popout or reload attaches to the
  running talk with `mine: false`).
- `start(api, session)`: local peer → `talk_start(session, 'device', null)`; relay client
  (`useEngines.active !== LOCAL`, the dictation rule) → `openTap('talk')` inside the gesture,
  `talk_start(session, 'client', ctx.sampleRate)`, then the tap streams 100 ms i16 batches to
  `talk_audio(id, pcm, speech.playedSeq())`. `stop(api)` → `talk_stop`; `open(api, session | null)` =
  `session ?? new_session()` then `start`, returning the session to navigate to (a talk already running elsewhere
  returns *that* session instead of starting a second).
- `Degraded` → caption `"No echo cancellation; headphones recommended"` (53's string). `Flush` → `speech.stop()`
  (cut + free the decoder) when the audio leg is ours. `TalkFinished` → tap closed, `talk` hold released, store `OFF`;
  `Error{message}` toasts.

### Audio — `src/lib/speech.ts`, `src/lib/mic-tap.ts`

- `Use` gains `'talk'` (→ `play-and-record` on iOS's `navigator.audioSession`).
- Talk leg: `setTalk(session | null)`; while set, every `SpeechStarted` whose `session` matches is claimed and started
  *queued* (`startQueued`: no cut, `next` carries over — the engine publishes one `SpeechId` per sentence back to back,
  §0.4) so the join is gapless. `push(speech, b64, seq)` records `seq` on `onended`; `playedSeq()` = highest ended
  `seq` of the current utterance (`null` before the first), reset per utterance — `PushAudio.played_seq`'s documented
  meaning. `stop()` remains the cut path (`Flush`).
- `mic-tap.ts`: `openTap(use)`, `wireTap(tap, emit, live)`, `closeTap(tap)` — dictation's capture graph
  (`theuth-tap` worklet, `Batcher`, silent gain to `destination`, ScriptProcessor fallback) extracted verbatim and
  shared; `dictation.ts` now uses it (behaviour unchanged; `dictation.test.ts` untouched and passing).

### RPC — `src/rpc/api.ts`, `src/rpc/events.ts`

`talk_start(session, sink, sample_rate)`, `talk_stop(id)`, `talk_audio(id, pcm, played_seq)`, `talk_status()` in `Api` +
`METHODS` (matches `bindings/methods.json`); `TalkEvent` in `WireEvent`.

### Route — `src/routes/talk.$session.tsx`

- `createFileRoute('/talk/$session')`; `routeTree.gen.ts` regenerated by the router plugin.
- `CodeMapPane` › `Header session popout={{kind:'talk', session}}` › a row: left `<aside>` transcript
  (`Transcript` + `Composer readOnly`), a 16 px edge handle with a chevron, centre column with `Orb` + `Subtitles`.
  Transcript collapsed by default; per-session choice in `localStorage['talk-transcript']`; `⌘⇧T`
  (`theuth:talk-transcript`) toggles. Phones (`useIsMobile`): a *Transcript* pill opens it as a full-height bottom
  `Sheet` (the `CodeMapSheet` pattern); the right-hand panels are `Header`'s, exactly as in `/c/$session`.
- Orb click: stop when the talk runs here (`talk.stop`), start when none runs (`talk.start`); `⌘T` / `Ctrl+T`
  (`theuth:talk`, shortcut id `talk`, rebindable) stops. `Esc` while thinking/speaking/holding → `api.cancel(session)`
  (§5.2: the agent's cancel; the talk stays on). Orb size = 60 % of the centre pane's narrower side, 160–440 px.
- When a talk runs on another session: orb idle, a muted *Talking in <title> — open* link.
- Simulator: `?sim=1` loops the scripted sequence (listen → partials → submitted → thinking → two sentences → holding →
  interrupted → listening → finished); `?sim=idle|thinking|speaking` runs to that state and holds. `src/lib/talk-sim.ts`
  is loaded with a dynamic `import()` behind `import.meta.env.DEV`, so production bundles do not contain it.
- `useSessionLoad(session)` extracted from `LiveSession` in `c.$session.tsx` (the page/agents/artifacts load, the
  settled path, the reconnect reload) and shared by both views.

### Components

- `src/components/talk/Subtitles.tsx`: two `Line`s (agent: foreground; user: `text-fg-secondary`) + the caption.
  A line is `h-[2lh]`; when its text overflows, leading words are dropped by bisection on the live element and a `…`
  leads — the tail stays. ≤ 150 ms opacity fades, `motion-reduce:transition-none`; the element owns its text node so
  the words stay while fading out.
- `src/components/chat/MicButton.tsx` + `src/lib/hold.ts` (pure reducer, `HOLD_MS 350`, `LOCK_PX 56`, `CANCEL_PX 56`,
  tap slop 10 px): tap → `onTap` (dictation); hold → `onRecord`; release over the control → `onStop(false)`; release
  outside or ≥ 56 px down → `onStop(true)`; ≥ 56 px up → locked (control becomes stop-and-send: red `Square`, plus an
  `X` cancel). Cues: a red dot + `m:ss` timer, *slide down to cancel* (fades as the finger slides down), an open lock
  that fills to a closed accent lock as the finger rises. `navigator.vibrate?.(15)` on record and lock (no haptics
  helper exists in the tree; iOS WebKit has no vibration API). Pointer capture, `touch-none select-none`, context menu
  suppressed; the `click` that ends a locking gesture is swallowed.
- `Composer.tsx`: the `AudioLines` voice-note button is now **Talk** (`Orbit`): `talk.open(api, session)` then
  `navigate('/talk/$session')`; `aria-disabled` + tooltip *Talking in <title> — open* when another session holds the
  talk (click opens it). The `Mic` button is `MicButton`; the dictating `LevelMeter` branch is unchanged. Visibility
  rules of 54 §0.8 kept (`canDictate` gates both; Talk hides while typing/recording/dictating as the note button did).
  New `readOnly` prop (the talk view): textarea `readOnly`, placeholder *Talking — speak, or stop the talk to type*,
  Send/Steer disabled, voice buttons hidden. `record()` gains a pending-stop guard so a hold released before
  `getUserMedia` resolves still stops (or discards) once the recorder exists.
- `AppSidebar.tsx`: **Talk** (`Orbit`) between *New chat* and *Agents*; click → `talk.open(api, null)` (creates the
  session, starts, invalidates the session list) → `/talk/$session`, whole-window like `/`; a `bg-success` dot while
  `talk.phase !== 'off'`.
- `Header.tsx`: optional `popout?: PopoutTarget` (default `{kind:'chat'}`); `lib/popout.ts` gains
  `{kind:'talk', session}` (`/talk/$session`, label `popout-talk-<id>`, closes with its session). A popped talk window
  attaches via `talk_status` at load; it never calls `talk_start`.
- `lib/shortcuts.ts` / `lib/hotkeys.ts`: `talk` (`Mod+T`, *Stop the talk*), `talk-transcript` (`Mod+Shift+T`).

## Deviations

- Orb files live in `src/components/orbs/` (the registry's `target`), not `src/components/ui/`.
- The shadcn CLI could not install the item here: `shadercn.run` is blocked by the network proxy (Zscaler 403), and the
  bare `orb` registryDependency resolves against the default shadcn registry (404). The two registry JSONs were taken
  from `github.com/shadcn-labs/shadercn/public/r/{orb,orb-20}.json` and their files/deps applied by hand — the same
  result the CLI produces. `components.json` keeps `"@shadercn": "https://raw.githubusercontent.com/shadcn-labs/shadercn/main/public/r/{name}.json"`
  (the mirror that works from this network; the canonical `https://shadercn.run/r/{name}.json` is equivalent).
- Brief item 6 says the Talk button is "hidden while a talk already runs on another session — show a tooltip naming
  it instead": kept visible, `aria-disabled`, tooltip names the session and a click opens that talk (the `dictReason`
  pattern; a hidden button cannot carry a tooltip).
- The orb click also *starts* a talk when none runs (the view can be reached by URL/popout before one exists); the
  brief only names stop. With no talk the caption reads *Tap the orb to start talking*; while one runs the only caption
  is `Degraded`'s line, as specified.
- `Composer` on a draft (`session === null`): Talk creates a plain `new_session()` (not the private/project create
  path the first typed message uses).
- `played_seq`: reported per *current utterance* (reset when the next `SpeechStarted` is claimed), which is what
  `PushAudio.played_seq` documents ("highest `seq` of the current utterance").
- `useLongPress` in `Composer.tsx` (Send/Steer's hold-to-interrupt) is untouched; the mic has its own reducer because
  it needs travel, lock and outside-release, which that hook does not model.
