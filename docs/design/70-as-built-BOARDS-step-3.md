## Deviations

1. **Two font files, not three.** Google Fonts serves Newsreader upright as one variable `wght` file (58 KB) for the 400+600 request; shipping it twice as `newsreader-400.woff2` and `-600.woff2` would be the same bytes. One `@font-face { font-weight: 400 600 }` covers both; italic is a static 400 (24 KB). OFL notice beside them as §6.3 requires.
2. **`--font-serif` sits in `@theme static`, not `@theme inline`.** Tailwind v4 omits theme variables no utility or `var()` uses; with no consumer until step 6 the token would not exist at runtime. `static` forces emission. Step 6 may move it back beside `--font-sans` once `.board-prose` consumes it.
3. **Marked rows use `bg-fg-accent/10` + an inset accent bar, not `--marker-tint`.** `--marker-tint`/`--edge-muted` are `board.css` tokens (§2.7, step 6). The Excerpt renders in chat and artifacts where `board.css` is absent, so it uses the existing accent token; step 6 can restyle `[data-line]` rows under `.board-prose` without touching the component.
4. **Sequence rest colour is the foreground, muted only while something is highlighted.** Whiteboard draws every inactive arrow `--edge-muted` always (R §B.5). In a chat with no anchor state that reads as a greyed-out diagram beside a full-ink `Graph`; the muted treatment engages when `highlight` is non-empty (the board, steps 4–5), which is when M4 needs it.
5. **Sequence labels in the diagram font (`--font-sans`), not mono 11.5.** Same as `Graph`; consistent across our two renderers in chat. `font-family` is a presentation attribute, so `board.css` can restyle it under the board.
6. **`Graph` nodes are focusable only with `onSelect`** (unchanged contract, "additive" per the step brief): `aria-description` is added for every node with a `ref`; step 5 wires `onSelect`/`highlight` from the anchor store and gets `role="button" tabIndex=0` from the existing branch.
7. **Excerpt has no live chip slot yet.** The header's meta span ends where step 7's chip goes; adding an empty slot now would be scaffolding.
8. **Test-side mocks for `DiagramFrame`** (`@/lib/rpc`, `@/lib/theme`, `@/lib/diagram-theme`, `@/components/ui/tooltip`): the frame reads the connection and CSS tokens, which the node test environment lacks. `SequenceView` also passes a server snapshot to `useSyncExternalStore` so it renders under `renderToStaticMarkup`.
9. **`__fixtures__/graph-architecture.json` re-synced** — the byte-identity test in `Graph.test.ts` failed on the base because step 1 added `ref`s to the crate fixture; the copy is now identical again.
10. `cargo check --workspace --tests` needs `just ts` once on a fresh worktree (step 1 deviation 8); `just ts-desktop` also regenerates `crates/desktop/ui/src/rpc/bindings` (gitignored).
