One user turn from the desktop to a model and back. The Composer calls the hand-written `send_input` client method (`Composer.tsx` L750–L777) which `rpc/client.ts` L106 serialises as JSON-RPC over the daemon's jsonrpsee WebSocket (`transport.ts` L22–L43). `api.rs` L2781 authorises, lets `forward::route` hand the call to the engine that owns the session, then asks the `Agents` actor (`supervisor.rs` L2901 → `human_input`), which delivers `UserInput` to the `Session` actor (`loop_.rs` L1348). `drive()` (L4901) loops: one `exec_chat_stream` (`backend.rs` L233) per round, every tool_use becomes `registry.ask(Invoke(..))` (L5900), until the model stops. Everything the session does is an `AgentEvent`; `rpc/src/bridge.rs` L171 subscribes once and pushes them to every connected client, where `store/reduce.ts` folds them into the session view.
