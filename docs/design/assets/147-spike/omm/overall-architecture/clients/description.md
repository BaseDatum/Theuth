The two human-facing programs. `crates/desktop/` is the Tauri shell (`src/`, plus Swift and Windows companions under `companion/` and `companion-windows/`) around the React UI in `ui/src/` (TanStack router + query, zustand stores, 29 component folders, 106 k lines). `crates/tui/` is the terminal client (iocraft). Both speak to the engine only through the RPC facade; the desktop UI's hand-written client is `ui/src/rpc/client.ts` over `transport.ts`. Size: 315 files / 66,688 lines (desktop figure includes ui/).
