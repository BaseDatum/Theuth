The tree-sitter + SQLite code index (`crates/codeindex/`, 50 files / 16,056 lines; 5 languages). It walks a root, parses definitions/references/imports, resolves imports per language, ranks files PageRank-style, and serves both the `code_*` tools to the model and the Here/Fit/Change lenses to the CodeMap panel. The actor (`src/lib.rs` L127–L218) is a kameo plugin started by `CodeindexPlugin::start`; see the child diagram for module flow.
