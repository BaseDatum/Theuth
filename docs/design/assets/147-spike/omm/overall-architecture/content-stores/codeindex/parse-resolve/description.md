The language layer: `src/parse.rs` (473 lines) runs tree-sitter tags per file; `src/lang/mod.rs` and `src/lang/imports.rs` (974 lines) know the five grammars and extract import specifiers; `src/resolve/{mod,rust,ts,py,go}.rs` (1,507 lines) turn specifiers into target files (Cargo manifests via `cargo_toml`, TS via `oxc_resolver`). Grouped here because the three directories only make sense together.
