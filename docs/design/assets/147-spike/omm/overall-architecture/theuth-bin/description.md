The `t` executable (`crates/theuth/`, 10 files / 3,323 lines). `src/main.rs` parses the CLI, builds the `runtime::Runtime` and starts every plugin in order (it imports 40 workspace crates); `service.rs`, `worker.rs`, `mcp.rs`, `secret_cli.rs`, `link_cli.rs` are its subcommands. It is the only crate that knows the full set of plugins, so it is the place where a new crate becomes part of the product.
