# 137G-U notes — endless memory controls (desktop UI)

Base: E's contract commits b3456be5 + e95ac353; round 2 merged E's phase B head 40bd3a21 (`--no-ff`) and regenerated the bindings.

## What was built
- **U1/U2 backlog row** (`MemoryPanel.tsx` `BacklogRow`): replaces the settle bar when `SessionMemory.backlog` is set (the backfill bar stays). Bar = the chat's lines summarized so far, `(units − backlog.lines) / units` (the mock's 18 % for 4,812 of 5,868). "Newest K lines shown in full" uses `K = lines − folded`; with `folded = 0` the line reads "Waiting lines are shown in full until summarized." ETA omitted when `eta_secs = 0` (paused/unknown). `batches of B` is `agent.endless.batch_units` from the cached `endless_settings_get`, else the engine default 16. `paused` with no `paused_by` (older engine) renders as paused by the user.
- **Fold now** lives in `MemoryFooter` (one mutation for the failing block and the backlog row). Round 2: the "Up to date / Folded" row is derived from the engine — the sum of `n` over the view's `mechanical: true` lines, shown while no backlog waits — so it also appears after the automatic fold and on a reopened panel, and it shrinks as excerpts merge into summaries. `Backlog.folded` cannot serve (the backlog is `null` once nothing waits) and E reports no folded total, so the wording is "N lines shown as excerpts" (the mock's "folded as excerpts" would overstate it once some excerpts sit under a placeholder or have merged).
- **Paused by spend**: limit = `max_usd_per_session_day` from settings, else $5; spent = `spend_today_usd`. **Resume for today** = `endless_pause(false)` (E: resuming past the cap sets the day override). The link opens Settings › Memory with `?focus=spend`: Advanced opens and the day-cap field takes focus.
- **U3**: the header's plain model text is now `SummaryModel` — the regular `ModelCombobox` (124 §5, the field every Settings model row uses) showing `SessionMemory.model`, "Use default" → `null`, hint from `model_source`. "Change model" (failing block, backlog row, paused row, folded row) clicks the picker's trigger (`#memory-summary-model`) instead of navigating to Settings. Every reply goes through `memoryMutation` into the `sessionMemory` cache (view size, retry, fold, pause, model).
- **U4**: agents are editable directly (Agent detail › Runtime and the Hire wizard both use `RuntimeFields` → `agent_put`), so "Memory summary model" is a `RuntimeFields` field writing `memory_model`; "Use default" sets it `undefined`, which `JSON` drops, so the file loses the key. The agent draft card was not touched (drafts are not the only edit path). The built-in theuth agent has no `AgentFile` runtime form and no `memory_model` RPC; not offered there.
- **U5**: no stable marker for the placeholders in the bindings, so they are matched on the text of `fold.rs` `folded_text` / `prefix_text`: `/^\([\d,]+ (?:lines? not yet summarized|older lines? folded to fit the view)\b/` (`lib/endless.ts` `isFoldedNote`). Both render as the `(earlier history…)` sentinel does (`ViewNote`, muted italic, plus a muted background as in the mock), are not zoomable and are out of the keyboard order. `mechanical` lines get an outline "excerpt" badge with the tooltip (and aria-label) "Excerpt — not a model summary; recall finds the original".
- **U6**: E's G10 note (`loop_.rs` `view_note`) reaches the transcript through `Turn::note("memory", …)`: a persisted user-role row `<memory>\n…\n</memory>`. Before, `classify` returned `null` for it, so it rendered as a user bubble with the raw tags. `injected.ts` now classifies the bare `<memory>` tag (one with attributes stays human text, like the notices) as `{ kind: 'memory' }`, and the reducer turns it into an `info` entry: the muted one-line `MessageInfo`. It is not an `engine` notice on purpose: those are hidden unless "Show theuth nudges" is on, and this line tells the reader what the model could not see.
- **U7**: the bindings now carry every 137F/137G key (optional), so the local `EndlessConfigX` type is gone; `ENDLESS_DEFAULTS` (`Required<Pick<EndlessConfig, …>>`) keeps the engine defaults for the placeholders. `jobs` ("Summaries at once (cloud)") had no documented range: 1–32 chosen (u8 in the engine, `max(1)` at use). `Count` gained `step`: below 1 the value is not floored (the USD rows). `bounded` now ignores an empty field — before, clearing a field with min 0 wrote 0, which for the day cap means "no cap".
- **U8**: `endless-fixture` flags `backlog`, `paused-user`, `paused-spend`, `folded`; `endless_fold`, `endless_pause`, `set_session_compactor_model` answer from the fixture and later `session_memory` calls return that answer.
