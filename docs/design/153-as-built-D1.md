## Design vs built
| Design | Built |
|---|---|
| §13.1 "or `kAXValue` settable" → editable | Only for roles outside the certainly-not row (a slider's settable value is still refused); a text role with `isEditable == false` → `unknown` (refuse only when certain). |
| §13.1 terminals/VS Code "unknown" | `assess(…, terminal:)` downgrades `.editable` → `.unknown` when the resolved profile is a terminal (lease, never direct insertion); never un-refuses. |
| §13.1 secure "editable, never Return" | `assess(payload: .text)` → `.editable`; `.returnKey` → `.certainlyNot(.secure)`. |
| §13.3 step 5 "still holds our session id" | `changeCount == write's` **and** an item carries `sessionType == session` (and `textType == text` when present). |
| §13.3 one lease slot | `begin()` over our own unsettled item keeps the previous snapshot (never restores our transient text as "the user's clipboard"). |
| §13.4 "any change containing our text" | One more occurrence of `text` in `value` than before; count-only elements: count grew. Other change → `.unknown(.userActed)`; caret-only move → `userActed`; `nil` read → `focusMoved`. |
| §13.4 direct insertion verifies once | `reads: 1` / `verify(reads: [r])`. |
| §9.1 `any_app` group default | Row `id == "any_app"` is re-labelled with the bundle id/name and `terminal ||= heuristics`; no rows → synthesized `AppProfile(id: bundleId, name:, terminal:)`, polish/learn off. |
