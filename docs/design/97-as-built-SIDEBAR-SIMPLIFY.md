## Deviations
- **Meeting row label wrapped in `<span>`.** `SidebarMenuButton` applies `[&>span:last-child]:truncate` (= `overflow: hidden`). With a bare text label the icon wrapper `span` is the last element child and its overhanging recording dot would be clipped. `<span>Meeting</span>` makes the label the last span instead. Commented in place.
- **`Tab` literal union + `to as Tab` in `onValueChange`.** Radix hands back a `string`; TanStack's `navigate` wants a route literal. The data (`GROUPS`) is typed with `Tab`; the single cast is on the Radix callback value, which can only be one of our own trigger values.
- **`value={tabOf(...) ?? ''}`** rather than `null`: Radix `Tabs` `value` is `string`; `''` matches no trigger, so a foreign path (e.g. the smoke's `/settings/general`) renders no active tab.
- **First tsc run was red** (`SidebarGroupLabel` removed per the brief's "if nothing else uses it" — `Desks` uses it). Restored in `bba87ff7`.
- Smoke test kept as `SectionTabs.test.ts` using `createElement`, since vitest's include is `src/**/*.test.ts` (a `.tsx` test is not collected and JSX in `.ts` does not transform).
- Chat row: `useSessionDrag(null, 'New chat')` and the sidebar comment at `:135-136` still say "New chat" — the former is the draft pane's name per the brief; the latter describes behaviour, not the label.

It does not render CSS, so the container-query fold (labels hidden under 20 rem / 40 rem) is asserted only as emitted class names — Tailwind 4.3 is expected to compile `@min-[20rem]:inline` to `@container (width >= 20rem)`; this was not inspected in the built CSS.
