## 4. Deviations from the design (consolidated; the step files argue each)

- **Surface (1):** `▸` not `▶` (no-emoji lint); async steps lower to mermaid `->`; `Anchor::Code.lines: Option<(u32,u32)>`; `check_path` also rejects `#` and — from step 9 — `:` (`path:12` is refused naming the `#L12` form).
- **Document (2):** `root` is *required* for a board (an un-rooted board can verify nothing); boards keep `Binding::Note`; the fence check runs on every document kind; two extra refusals (component-named fences, scheme-less `path#L` links); one prompt block per plugin so `## Boards` rides in the document block; `Callout` variants are the crate's.
- **Desktop (3):** two font files, `--font-serif` in `@theme static`, marked rows use `bg-fg-accent/10` outside `board.css`, `Sequence` rest colour is the foreground until something is highlighted, labels in `--font-sans`.
- **Reader (4):** route switch in `NotePage`'s `Note` (meta arrives with `doc_open`); `links.isValidLink` admits `code:` in the shared schema (the link gate, §5); bare-path pins show the file's first excerpt; sheet is `position: absolute` inside the shell, not the modal `Sheet`; `connecting` renders nothing.
- **Tour (5):** `tour.stops: TourStop[]` (explanation stops, stage per stop) instead of `Anchor[]`; unit clicks via `pointerdown/up` (pointer capture); `T` outside a diagram = Tour this board; stage is the in-flow view in a scroller, not a `fullscreen` prop; no focus trap.
- **Sections (6):** rail breakpoint is the viewport, the pane takes the rail's place below 1940 px; `Graph` labels keep `--font-sans` (measured layout); collapsed bodies unmount; anchor count is static.
- **Live (7a/7b):** no `text_sha` → `same` when the range exists; `moved` keeps the requested length; stale index + no definition → `changed`; whole batch fails on one bad path; reader cache keyed by anchor, not `(path, mtime)`; excerpts keyed `excerpt:<blockId>`; `code:` spans show only `missing` in practice; the insert-time check fails open; root read from the frontmatter, not `DocMeta`.
- **Ask (8):** Ask prefills, never sends; `askBoard` reuses NoteChat's path; `step <n>` is 1-based; a board create breaks a TOOL-COLLAPSE run; the card's section comes from the transcript; binding only when no entry exists; two `doc_list` calls for the notes list.
- **Step 9:** see `70-as-built-BOARDS-step-9.md` §Deviations — the reference boards were drawn from `Draw a board: …` prompts (the plain question routed inline in 3–7 of 8 cases), prompt D reworded, the skill tuned beyond §3.2 from the runs, `board-check --reference` thresholds, tolerant JSON in the checker.

## 5. Findings that outlived their step

1. **Excerpt fidelity is a machine check, not a rule (step 2).** 4 of 8 excerpts in the first four boards were retyped, dedented or off by one; the model retypes however the skill words it. Closed by 7b's insert-time `Locate` refusal (an `Excerpt` that does not quote the tree never lands) — every excerpt of every step-9 board is verbatim by construction (`board-check`: 100 % on 12 of 12 boards checked).
2. **The link gate (step 4).** BlockNote's Link mark dropped every href whose scheme is not in tiptap's allowlist at import, paste and render — no `code:` link of steps 2's boards survived into the Yjs document; only the derived `note.md` kept them. Fixed once in the shared schema (`links.isValidLink`); a helper binary older than that fix still flattens them, so any board drawn against an old `t` has no prose anchors.
3. **Cache and `moved` caveats (step 7b).** The reader caches per anchor key for the life of the open board (no mtime source; **Verify** drops the cache); `moved` starts at the definition's `line_start`, so an excerpt that opens with a doc comment reports one line off after lines are inserted above (7a's `locate.rs`; not changed).
4. **`doc_read(blocks=[…])` without `format="markdown"` returns the whole outline (step 8).** The prompt block and skill now say `format="markdown"` (step 9); the outline form still ignores `blocks`.
5. **The documents helper must sit beside `t` (step 8).** Without `target/debug/theuth-documents-59.5`, `doc_read` fails and the agent falls back to answering from code; step 9 copied `packages/documents/dist/theuth-documents-59.5` beside the binary before every run.
6. **The board skill's front matter was invalid YAML since step 2 (step 9).** `description:` carried an unquoted `: ` ("the code: link"), so `gray_matter` failed and the skills index showed `- board: ---`; the model saw no description of the skill until step 9 quoted it. `pdf.md` has the same defect (not touched).
7. **`path:line` refs passed the grammar and died in the reader (step 9).** Round 1's only board wrote every `ref` as `crates/rpc/src/api.rs:1` — valid as a path, missing as a file. `check_path` now refuses `:`; the refusal names the `#L<n>` form.
8. **Routing is the weak point, not drawing (step 9).** With the tuned prompt and a visible skill description, sonnet-4-5 boards 5 of 8 "how / walk me through" prompts and stays inline on 2 of 2 comparisons; once it draws, `board-check` passes on the third attempt for each reference topic. The failure modes it keeps: two excerpts instead of three, one un-`ref`'d return step or non-code node, `###` for section headings once.
