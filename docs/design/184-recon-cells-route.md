ANSWER: a note's cells run on the engine that holds the mesh documents-hub lease when ► is pressed. That is not the viewer's engine, not the creator, and not a doc root. Every cell RPC on a note is forwarded to that engine, so cwd, `~`, interpreters, secrets, the process and the cell_runs row are all the hub's. This is deliberate (design 171 W-d), not a Yjs need.
