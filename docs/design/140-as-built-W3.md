## Deviations (closest correct thing; each recorded here)

1. **`memory: clear` only with `when:`.** The schedule parser refuses `memory:` without a sensor (`crates/schedule/src/file.rs` "memory: needs when:"); a clock-only file clears the frame on every fire anyway (34 D4), so the `every: 0s` variant omits the key and the window variant keeps it.
2. **The schedule file is written, not `Put`.** `schedule::Put` would re-render the file in the schedule crate's key order; §8.1 asks for the plugin's text. `write()` validates with the schedule crate's parser and writes atomically; the dir watcher reconciles within ~300 ms (the loop fires on its own; `RunOnce` right after Start could see "no such schedule" for that window).
3. **Study spend = `SessionCostQuery(session).total.returned` (USD).** `Store::budget_spent` is owner-only; the tree total is what the design asks for. Without the agent actor (tests) spend is 0.
4. **Restore{n} is executed by the model, not the plugin.** No W2 API applies a patch to the working tree without committing; Restore records a `restore` event (clears the attention row) and a ★ priority-3 idea telling the next experiment to `git apply` the saved patch (working tree only) and measure it again — "it is not trusted from memory" holds. A plugin-side `git::apply_patch` would make this exact; hand-off to W2/closer.
5. **StopNow resets the worktree immediately** (not "at the next begin"): after StopNow there is no next begin and finalize needs a clean tree.
6. **`deadline:`** has no spec field in C's `StudySpec`; `StopReason::Deadline` is never produced. `budget.hours` covers it.
7. **Per-experiment `cost_nanos` stays 0.** The ledger has no per-turn attribution to copy into the row; the study total is live through `SessionCostQuery`.
8. **Typing in the study session is not recorded as a steer** (§8.6): that needs an agent input event the plugin does not receive; steers come through `Steer`, the tool and RPC.
9. **A pause/stop when the schedule actor is absent** logs a warning; the ledger state is authoritative and `Begin` refuses fires for a study that is not running/paused, so the loop stops either way.
10. **`window:` / `StartWhen::Window.sensor` must be a bare sensor file name** (`idle.py`): 40's `when:` grammar refuses path separators, so the design's `sensors/idle.py` example does not parse. `schedule_file::write` refuses the file with the parser's message and the study ends `failed` with it; the draft card should offer the sensor file name (hand-off W6/W4).

- **W6 `novelty::check`:** `flagged_before` = the previous experiment had `similar` rows; the actor records `novelty_flag {n}` events.
- **W6 `review::review`:** return `Flagged` for SUSPICIOUS; the actor turns it into `Reverted` under `on_suspicious: revert` and does the git revert itself.
