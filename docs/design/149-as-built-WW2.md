## 3. Deviations from the design (and why)

1. **Pills have no DWM shadow.** §7.4 #2 asks for opaque, rounded, with a shadow. Four capsules with transparent gaps need per-pixel transparency, which a WinUI 3 top-level window does not have; the W6 spike proved region pass-through works, so the stack is one window shaped with `SetWindowRgn` — and DWM draws no shadow for a regioned window. Each pill carries a 1 epx ink-14 % hairline instead (the mock's inset ring). The same holds for the Ask pill's 28 epx capsule. Retest route: `WS_EX_LAYERED` + `LWA_COLORKEY` on a newer App SDK, or one window per pill.
2. **Panels are rounded at DWM's radius (~8 px), not 24.** The Attention and agents panels keep the system shadow via `DWMWA_WINDOW_CORNER_PREFERENCE = ROUND`; a 24 px region would cost the shadow (deviation 1). The cards inside use the design's radii (option rows 10, caps 4, bubbles 14).
3. **"this PC"**, not "this Mac", for the local host group.
4. **Remote rows** list sessions owned elsewhere that are `running` or were updated in the last 10 min (`AgentsModel.RemoteRecent`); the design names no window and listing every historical remote chat would swamp the panel.
5. **The Done zone** of the empty state (§3.4, ≤ 4 rows of asks/answers) is W3/W6's existing `DoneZone` under the empty block, unchanged.
6. **`FooterVerb`** in C# is `{Stop, Clear, Snooze}` only; the Mac stub also lists reply/point/talk/legend as footer verbs — on Windows those are the reply row and the header, which `CardAnatomy.Reply` / `Keys` carry. `CardHeader` has no `glance` field (the panel reads `Panel.Headline` directly).
7. **Hold pill wording** uses "Esc undo" (the Windows key name) where the design writes "⎋ undo".
8. **Mesh name**: the Core `MeshStatus` DTO (W4's) has no `mesh_name`, so remote groups read "‹peer› · on 🌐 mesh".
9. **P on a card / the rail's point glyph** raise `Surfaces.PointRequested(Card?)` and close the panel; the `screen_context` call and the `files` attachment are WW3's point-and-say (§3.7) and are wired at integration. Until then the press is logged.
10. **Tooltip "Pausing ‹desk›"**: desk rows pause with `agent_pause(name, true)` as §3.2 says; a desk whose session is live and running is still a desk row (named "‹name› · desk"), so ✕ pauses rather than cancels — the design's table reads the same way.
